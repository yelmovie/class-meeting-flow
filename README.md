# 학급회의 시간 — 우리반 학급회의

초등학교 교실에서 학급회의를 처음부터 끝까지 안내하는 수업용 정적 웹앱입니다. 교사가 전자칠판이나 태블릿에 띄워 두면, 아이들이 말하고 듣고 함께 정하는 회의 흐름을 단계별로 따라갈 수 있습니다.

빌드 과정이 없습니다. `public/` 폴더를 그대로 서빙하면 동작합니다.

## 주요 기능

- **10단계 회의 흐름** — 회의 준비 → 회의 순서 고르기 → 우리의 약속 → 지난번 약속 돌아보기 → 우리 생각 적기 → 생각 모아 손들기 → 함께 토의하기 → 손들어 정하기 → 함께 정한 일 적기 → 오늘 회의 한눈에 보기
- **회의 순서 고르기** — 2단계에서 오늘 진행할 단계를 골라 회의 분량을 조절할 수 있습니다.
- **자동 저장·이어하기** — 브라우저 로컬 저장소(localStorage)에 진행 상황을 저장하고, 다시 열면 이어서 진행합니다.
- **회의 기록** — 지난 회의 기록을 목록으로 보관하고 다시 열어 볼 수 있습니다.
- **A4 인쇄** — 오늘 정한 일을 교실 게시물 한 장으로 만들어 인쇄합니다. 게시물 모양은 여러 가지 중에 고릅니다.
- **JSON 백업·복원** — 회의 기록을 JSON 파일로 내려받고 다시 불러옵니다. 회의 기록 형식이 아닌 파일은 걸러 냅니다.
- **타이머** — 화면 안에서 회의 시간을 재고, 작게 접어 둘 수 있습니다.
- **결석 처리** — 오늘 빠진 인원을 따로 세어, 결석생이 있어도 손든 수 검증에 걸려 회의가 멈추지 않습니다.
- **복구 화면** — 화면 그리기에 실패하면 새로고침 · 기록 파일 내려받기 · 기록을 버리고 새로 시작 중에서 고를 수 있습니다.

## 로컬 실행

정적 서버로 `public/` 폴더를 서빙합니다.

```bash
npx serve public
# 또는
python -m http.server 8000 --directory public
```

파일을 `file://` 로 직접 열면 일부 기능이 동작하지 않으므로 정적 서버를 쓰세요.

## 배포

Vercel에 정적 사이트로 배포합니다. 리포 루트의 `vercel.json`이 `outputDirectory: "public"` 을 지정하므로 별도 빌드 설정이 필요 없습니다. `vercel.json` 에는 에셋 장기 캐시, HTML·JS·CSS 재검증, 기본 보안 헤더(`X-Content-Type-Options`, `Referrer-Policy`)가 들어 있습니다.

`app.js` · `styles.css` 를 수정하면 `public/index.html` 의 `?v=` 쿼리스트링을 함께 올려야 브라우저가 새 파일을 받아 갑니다.

## 브라우저 요구사항

- 전자칠판·태블릿 **가로 화면** 기준으로 만들었습니다.
- Chrome 계열 최신 브라우저(Chrome, Edge, 웨일)를 권장합니다.
- 자바스크립트가 켜져 있어야 하고, 자동 저장에 localStorage를 씁니다. 시크릿 모드나 저장소 차단 환경에서는 이어하기가 동작하지 않습니다.

## 폴더 구조

```
public/          배포되는 전부 (index.html, app.js, styles.css, assets/)
asset-bank/      미사용·원본 에셋 보관소 — 배포에 포함되지 않음
vercel.json      배포 설정 (출력 디렉터리, 캐시·보안 헤더)
docs/reviews/    점검 기록
```

`asset-bank/` 는 화면에 쓰지 않는 원본·후보 에셋을 모아 둔 곳입니다. 용량이 크고 배포에 필요 없어 `.gitignore` 로 제외합니다. 실제로 쓰는 에셋만 `public/assets/` 에 들어갑니다.
