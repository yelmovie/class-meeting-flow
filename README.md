# 학급회의 시간 — 우리반 학급회의

초등학교 교실에서 학급회의를 처음부터 끝까지 안내하는 수업용 정적 웹앱입니다. 교사가 화면에 띄워 두면 아이들이 말하고 듣고 함께 정하는 회의 흐름을 단계별로 따라갈 수 있습니다.

## 주요 기능

- 10단계 회의 흐름 안내 (열기 → 안건 나누기 → 의견 모으기 → 결정 → 마무리)
- 자동 저장 및 이어하기 (브라우저 로컬 저장소 사용)
- 회의 결과 A4 게시물 인쇄
- JSON 파일로 기록 백업 및 복원

## 로컬 실행

정적 서버로 `public/` 폴더를 서빙하면 됩니다.

```bash
npx serve public
# 또는
python -m http.server 8000 --directory public
```

## 배포

Vercel에 정적 사이트로 배포합니다. 리포 루트의 `vercel.json`이 `public/`을 출력 디렉터리로 지정하므로 별도 빌드 설정 없이 배포됩니다.
